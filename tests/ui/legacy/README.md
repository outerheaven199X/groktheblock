# Retired UI tests (pre-v6 design)

`ui_r3.py` and `ui_r4.py` test the v5 pixel UI (Bungee/Geist Pixel, `go()`/`cur()` globals, `.sigrow`, `.calchip`, `?`-shortcut dialog, fetched `../examples/` listing).
That UI is archived at `ui/legacy/index.v5.html` and is no longer served as `ui/index.html`.
v6 (branch `ui/v6-20261028`) replaces them with `tests/ui/ui_v6.py`. They are kept for history and are NOT RUN against v6.
